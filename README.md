# 5G-Network-Data-Analysis-Dashboard-to-visualize-network-performance
 Interactive 5G Network Data Analysis Dashboard to visualize network performance, download/upload speeds, latency, signal strength, dropped connections, data usage, and network congestion across 4G and 5G technologies.
#  5G Network Data Analysis Dashboard

##  Overview
An interactive dashboard designed to analyze telecom network performance and visualize key metrics across different carriers and network technologies.

##  Key Features
- 📶 Average Download & Upload Speed
- ⚡ Network Latency & Signal Strength
- 📡 4G, 5G NSA & 5G SA Analysis
- 📉 Dropped Connection Analysis
- 📊 Carrier-wise Download Speed Comparison
- 🌐 Data Usage by Location
- 🚦 Network Congestion Analysis
- 🎛️ Interactive Filters

##  Objective
